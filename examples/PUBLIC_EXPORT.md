# Public example export

The public repository and release bundle include only original test artwork, selected demonstration images, source locators, inventories and public documentation. Private production source art and the supplied production orchestration prompt are excluded.

For portability and privacy, the release builder rebases local example request references and manifest source paths to package-relative paths. These exported JSON files are portable prompt/manifest copies, not the byte-exact original execution records. Original image SHA-256 values remain unchanged. Exact local requests, raw output records and machine paths stay in the working project and are not included in the public bundle.

The image service did not expose a model/version, seed, quality setting or cost. The release does not invent those fields or claim deterministic image reproduction.
