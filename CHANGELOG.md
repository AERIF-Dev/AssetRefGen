# Changelog

## 0.2.0

- Published the first stable AssetRefGen release, including Single Asset, Roster Mode, and folder batches with Quick and Detailed review presets.
- Added versioned Codex installation from `skills/assetrefgen`, and standalone skill and full project ZIPs with SHA-256 checksums.
- Included a public example gallery, original roster fixtures, and one complete live four-view reference set with provenance and visual QA.
- Added a local project validation command and a CI workflow for checks that use existing fixtures.

## 0.2.0-rc.1

- Added Roster Mode for producing separate reference sets from multiple subjects in one concept sheet.
- Added folder batch intake for individual images and roster sheets, with per-asset progress, file validation on resume, and tracking of interrupted work.
- Added quick and detailed review presets for roster and batch work, with bounded major corrections per asset.
- Added all-masters-first and per-asset production orders, source locator and gallery options, and partial review packaging with omission details.
- Extended the existing single-asset workflow so each roster subject has its own source evidence, identity record, master, views, and QA.
- Added install and quickstart guides, sample prompts, and original examples for release review.
